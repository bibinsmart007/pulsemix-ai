**Output:** rendered MP3 320 + WAV via PulseMix Balanced mode (-10 LUFS).

How to use this file:
1. Replace each `https://www.youtube.com/watch?v=...` placeholder with the real link.
2. Tracks with `[CUE]` are **drop moments** — do NOT auto-mix them. Drag them onto the timeline at a specific timestamp and use a hard cut on both sides.

## Important reminders

- **Loudness target: -10 LUFS Balanced.** Don't switch to Loud for a PA — the limiter will hit hard and the bass will mud out.
- **Vocal collisions:** after rendering, listen at minute marks `Phase 1→2`, `Phase 2→3`, `Phase 3→4`. If two languages are layered, manually shorten the crossfade on that boundary in PulseMix.
- **`[CUE]` tracks: use stem `vocals=mute, drums=full` if the track is mostly percussion** — the analyzer might mis-detect BPM on chendamelam. Override with `sync_mode=BYPASSED` for that one.
- **MC duck:** if you'll have a host with a mic, leave 30-second silence gaps between Phase 3 and 4 so the host can take it. Or use ducking in PulseMix's transition settings (`duck_amount_db: -12`).
- **First 2 minutes set the tone.** If `Aaromale` doesn't grab the room in 30 seconds, swap track 1 for `Tum Hi Ho` and push `Aaromale` back to slot 3.

## Quick load via API (alternative to UI)

If you want to skip dragging in the UI and load everything by URL:

```powershell
# After replacing the URL placeholders above, extract them all:
$urls = Select-String -Path tracklist_template.md -Pattern "https://www\.youtube\.com/watch\?v=\S+" -AllMatches |
        ForEach-Object { $_.Matches.Value } | Where-Object { $_ -notmatch "\.\.\.$" }

foreach ($u in $urls) {
    Invoke-RestMethod -Method Post -Uri "http://localhost:8000/api/import" `
        -ContentType "application/json" -Body (@{youtube_url=$u} | ConvertTo-Json)
    Start-Sleep -Seconds 1
}
```

This kicks off background extraction for each track. Watch progress in the PulseMix UI's library view.
